# ドットシティ — リリース前の動作確認

main にマージする前に、このブランチの内容を自分で触って確認するためのメモです。

## いちばん手軽（この Cloud Agent が動いている間）

エージェントがプレビュー用サーバーを起動している場合:

| どこで見るか | URL |
|---|---|
| PC（Cursor のポート転送） | http://localhost:8765/simcity/ |
| スマホ・別端末（一時トンネル） | エージェント返答に書いた `*.trycloudflare.com/simcity/` |

Cursor Desktop では、エージェント画面右上のプラグ（Ports）アイコンから **8765** が転送されているか確認できます。

トンネルは **このエージェント VM が動いているあいだだけ** 有効です。止まったら URL は使えなくなります。

## 自分の PC で確認する

```sh
git fetch origin
git checkout cursor/dotcity-sfc-sim-6de1
./scripts/preview.sh
```

ブラウザで http://127.0.0.1:8765/simcity/ を開く。

ポートを変えたいとき: `PORT=9000 ./scripts/preview.sh`
