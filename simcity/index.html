あそびかた

市長になってまちをそだてよう。SFC版シムシティと同じく、じゅうたく(R)・しょうぎょう(C)・こうぎょう(I)のゾーンに、 どうろとでんせんをつないで発展させます。

  1. せきたん（またはげんしりょく）はつでんしょを建てる
  2. R / C / I ゾーンを置く
  3. どうろでゾーンをつなぐ
  4. でんせんではつでんしょとゾーンをつなぐ
  5. けいさつ・しょうぼう・こうえんで住みよくする
  6. じんこうが増えたらスタジアム・みなと・くうこう

スマホ操作: 下のツールを選んでタップ／ドラッグで建設。 「移動」ツールかミニマップで画面をうごかす。ピンチでズーム。

都市ランク: むら → まち(2,000) → とし(10,000) → しゅと(50,000) → だいとし(100,000) → きょだいとし(500,000)
