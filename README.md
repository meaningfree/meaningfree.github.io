# demo
This is a demo project for learning GitHub basics.

## マッチぼうパズル

`matchstick/index.html` をブラウザで開くだけで遊べる、子ども向けのマッチ棒パズルです。
マッチ棒を決められた本数だけ「うごかす・ふやす・とる」して、式を正しくします。

- 全28問・4ステージ。どの問題も答えは1つだけ（ソルバーで確認済み）
- ＋ − ＝ のマッチ棒も動かせる（例: 5−7＝2 → 5＝7−2）
- 何もない場所に数字を作る問題もある（例: 4＋9＝0 → 1＋9＝10）
- 置き場所の点線は出さない。置きたい場所をタップすると近い位置に収まる
- 問題の種類は色とアイコンで区別（うごかす＝青、たす＝緑、とる＝オレンジ）
- 問題の順番はステージ内でシャッフル（「じゅんばんを シャッフル」でやり直せる）
